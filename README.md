# Sanjana Y — Portfolio Website

A responsive, modern professional portfolio website built with **HTML, CSS and JavaScript**, based on the information in Sanjana Y's resume.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colors, responsive styling and animations/transitions
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — profile photo extracted from the uploaded resume

## Run locally
1. Download and extract the ZIP file.
2. Open the `sanjana_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

You can also open the folder in VS Code and use the **Live Server** extension.

## Customize
- Update contact details and project descriptions in `index.html`.
- Replace `assets/profile.jpg` to change the profile picture (keep the same filename).
- Change colors and layout in `style.css`.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files and folders from this project.
2. Open the repository's **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish your site and open the URL shown in the Pages section.
